# 大安寺植福點燈系統

和初級班報名同一個 GitHub（xianfosi / daansi），放在 `lamp` 資料夾，但用**另一份** Google 試算表，兩邊互不影響。

- 信眾登記頁：`https://xianfosi.github.io/daansi/lamp/`
- 後台：`https://xianfosi.github.io/daansi/lamp/admin.html`

| 檔案 | 用途 |
|---|---|
| `index.html` | 信眾登記、查詢、回報繳費 |
| `admin.html` | 後台 |
| `core.js` | 核心邏輯（命卦、太歲、金額、名額、匯入）— 網頁和 Apps Script 共用 |
| `api.js`、`config.js` | 連線設定 |
| `點燈名單範本.xlsx` | 整理過去紙本資料用的 Excel 範本 |
| `apps-script/Lamp.gs` | Apps Script 外殼 |

## 一、建立 Google 試算表（約 10 分鐘）
1. 用大安寺的 Google 帳號新建試算表，命名「大安寺植福點燈」。
2. 「擴充功能」→「Apps Script」。
3. 把預設的「程式碼.gs」改名為 **Core**，內容換成 `core.js` 全部內容。
4. 按「＋」→「指令碼」，新增一個 **Lamp**，貼上 `apps-script/Lamp.gs` 全部內容（可先改 `INITIAL_PASSWORD`）。
5. 上方函式選 `setup` →「執行」→ 授權。試算表會出現「點燈單、點燈明細、系統設定」三個工作表。
6. 「部署」→「新增部署作業」→「網頁應用程式」，執行身分：我；存取：所有人 → 複製網址。
7. 貼到 `config.js` 的 `API_URL`。

> 修改 Core 或 Lamp 後：「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」。

## 二、上傳到 GitHub
在 `daansi` repository 按「Add file → Upload files」，把整個 `lamp` 資料夾拖進去（Chrome 可以直接拖資料夾），按「Commit changes」。

## 三、上線前到後台「設定」填好
- 匯款帳戶（銀行、代碼、分行、帳號、戶名）
- 登記截止日（過了自動關閉線上登記）、繳費說明
- 燈種價格與名額（消災祈福燈預設 95 盞）
- 閏月算法（請向講師確認後選擇，預設「閏月照本月算」）

## 四、整理過去的紙本資料
1. 後台「匯入／匯出」→ 下載 Excel 範本。
2. 師兄姐在「點燈名單」工作表一盞燈填一列，同一戶填同一個單號（看「範例」工作表）。
3. 回到後台上傳，系統先檢查、再匯入。匯入的資料就是「去年紀錄」，信眾輸入聯絡人姓名＋電話就能帶出。

## 五、每年換新年度
後台「設定」改年度、干支、活動名稱，並更新生肖與命卦規則。今年的資料自動成為明年的「去年紀錄」，年度下拉選單可以查看歷年資料。

## 六、電話或紙本登記
後台「點燈單」→「代客登記」，會開啟登記頁的工作人員模式（截止後也能登記）。
